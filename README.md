# AdForge - Website Ad Builder

A Progressive Web App (PWA) for creating and showcasing website advertisements with 3D effects, comments, likes, leaderboards, and analytics.

![AdForge Logo](./public/icon-512x512.png)

## Features

- **6 Website Showcases** - Piikacsu's Games, ABENERP, Black Hole Explorer, Mc Locate, Emoji Kitchen Mixer, Piikacsu AI
- **3D Card Effects** - Interactive tilt and flip animations
- **Comment System** - Leave comments on any website
- **Like & Rating System** - Heart likes and star ratings
- **Leaderboard** - Rankings with engagement stats
- **Insights Dashboard** - Analytics and activity tracking
- **Theme Toggle** - Dark/Light/Matrix/Rainbow themes
- **PWA Support** - Installable on iOS, Android, Windows, Mac
- **QR Code Generator** - Share ads with QR codes
- **PNG Export** - Download ads as images

## Tech Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v3
- Framer Motion
- Three.js + React Three Fiber
- GSAP + ScrollTrigger
- shadcn/ui

## Installation

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

The `dist/` folder contains the static build ready for deployment.
